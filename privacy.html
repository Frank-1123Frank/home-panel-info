Privacy Policy

Effective 6 October 2026

Home Panel is personal-use software that runs locally on the user’s own Windows device. This policy explains how its optional Google Calendar connection handles information.

Information accessed

If the user chooses to connect Google Calendar, Home Panel requests read-only Calendar access. It may retrieve calendar names, event titles, event dates and times, and display colours for calendars selected by the user.

How information is used

Google Calendar information is used only to show upcoming events on the user’s local Home Panel dashboard. Home Panel cannot create, modify, or delete Google Calendar events.

Local storage

OAuth authorization tokens and cached calendar display data are stored locally within the user’s Windows application-data folder. They are not uploaded to the developer. Cached information allows the dashboard to remain useful temporarily when the device is offline.

Sharing and advertising

Home Panel does not sell, rent, share, or use Google user data for advertising. It has no analytics, telemetry, advertising network, cloud database, or remote administration service.

Retention and deletion

The user can disconnect Google from Home Panel at any time, which removes the locally stored authorization token and stops future Google Calendar access. The user can remove all remaining locally cached Home Panel data by deleting the Home Panel folder within Windows Local AppData. Authorization can also be revoked through Google Account permissions.

Security

Home Panel’s local server listens only on the device’s loopback address. Users should protect their Windows account and physical access to the device because locally stored dashboard information is available to that Windows account.

Google API policy

Home Panel’s use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

This website

This informational website does not use cookies, analytics, advertising, account registration, or tracking.

Contact

Privacy or support questions can be submitted through the Home Panel support page.

Changes

If Home Panel’s handling of Google user data changes, this policy will be updated before the changed functionality is used.
